# 📸 Photobooth Audiova

Logiciel de photobooth pour Windows, pensé pour les écrans tactiles et les prestations événementielles
(mariages, soirées, entreprises).

**Logiciel conçu et fabriqué par Audiova France.**
En cas de souci ou pour une amélioration, contactez-nous : **contact@audiova.eu**

## ⬇️ Télécharger

👉 **[Télécharger la dernière version](https://github.com/audiovaFR/photobooth-audiova/releases/latest)**

Sur la page qui s'ouvre, descendez jusqu'à **Assets** et cliquez sur **Installer.Photobooth.Audiova.exe**.
⚠️ Ne cliquez pas sur « Source code » : ces liens sont ajoutés automatiquement par GitHub et ne contiennent pas le logiciel.

Une fois installé, le logiciel se met à jour tout seul : *Réglages > Général > Rechercher une mise à jour*.

## ✨ Fonctionnalités

- Pilotage direct des reflex Canon (aperçu fluide), ou webcam
- Impression 10x15 et bandelettes 5x15 avec coupe (testé avec DNP DS-RX1HS), limite de tirages par événement
- L'invité choisit son format au début de la séance : photo 10x15 ou bandelettes
- Fonds personnalisés avec éditeur de placement des photos (modèles tout prêts, aimantation)
- Partage par QR code et par e-mail, galerie en ligne
- Noir et blanc en un appui, « Refaire / Garder », aide au cadrage
- Modes clair / sombre / automatique selon le soleil, animations d'accueil au choix
- Télécommande depuis le téléphone, diagnostic du matériel, mode Prestation

## 🛠️ Installation

1. Lancez l'installateur du Photobooth, puis redémarrez le PC.
   Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires > Exécuter quand même*.
2. Dans le Photobooth : cadenas > code (**1234** par défaut, à changer).
3. Suivez l'onglet **🚀 Mise en route** : il vous guide étape par étape (appareil photo Canon, imprimante DNP,
   coupe des bandelettes, fonds), puis masquez-le une fois tout réglé.

Pour les appareils Canon, installez **digiCamControl** (gratuit, digicamcontrol.com) : le Photobooth s'en sert
uniquement pour le kit Canon qu'il contient. Inutile de l'ouvrir, mais ne le désinstallez pas.
