# 📸 Photobooth Audiova

Logiciel de photobooth pour Windows, pensé pour les écrans tactiles et les prestations événementielles
(mariages, soirées, entreprises).

**Logiciel conçu et fabriqué par Audiova France.**
En cas de souci ou pour une amélioration, contactez-nous : **contact@audiova.eu**

## ⬇️ Télécharger

👉 **[Télécharger la dernière version](https://github.com/audiovaFR/photobooth-audiova/releases/latest)** — fichier `Installer_Photobooth_Audiova_X.Y.Z.exe`

Une fois installé, le logiciel se met à jour tout seul : *Réglages > Général > Rechercher une mise à jour*.

## ✨ Fonctionnalités

- Pilotage direct des reflex Canon (aperçu fluide), ou webcam
- Impression 10x15 (testé avec DNP DS-RX1HS), limite de tirages par événement
- Fonds personnalisés avec éditeur de placement des photos (modèles tout prêts, aimantation)
- Partage par QR code et par e-mail, galerie en ligne
- Noir et blanc en un appui, « Refaire / Garder », aide au cadrage
- Modes clair / sombre / automatique selon le soleil, animations d'accueil au choix
- Télécommande depuis le téléphone, diagnostic du matériel, mode Prestation

## 🛠️ Installation

1. Installer **digiCamControl** (gratuit, digicamcontrol.com) : nécessaire pour les appareils Canon.
2. Installer le pilote de votre imprimante photo.
3. Lancer l'installateur du Photobooth, puis redémarrer le PC.
4. Dans le Photobooth : cadenas > code (1234 par défaut, à changer) > **Diagnostic**.
